# API Documentation

This document describes the API endpoints available in the application.

## Base URL

When running locally with Docker, the base URL is typically:
`http://localhost:3000`

## Endpoints

### 1. Convert SVG to GCode

Converts an uploaded SVG file into GCode formatted for the Joto device.

- **URL:** `/convert`
- **Method:** `POST`
- **Content-Type:** `multipart/form-data`

#### Parameters

| Name | Type | Description |
|---|---|---|
| `file` | File | The SVG file to convert. |

#### Response

- **Success (200):** Returns the generated GCode file as a download (`converted.g`).
- **Error (400):** "No SVG file uploaded."
- **Error (500):** "Error converting SVG to GCODE."

#### Example Usage

```bash
curl -X POST "http://localhost:3000/convert" \
     -F "file=@/path/to/image.svg" \
     -o output.g
```

---

### 2. Send GCode to Joto (Jot)

Uploads a GCode file to the Joto device and triggers the drawing process.

- **URL:** `/jot`
- **Method:** `POST`
- **Content-Type:** `multipart/form-data`

#### Parameters

| Name | Type | Description |
|---|---|---|
| `file` | File | The GCode file to send (usually generated by `/convert`). |
| `baseUrl` | String | The base URL (including protocol) of the Joto device on the network (e.g., `http://192.168.1.100`). |

#### Response

- **Success (200):** "File uploaded successfully."
- **Error (400):** "No GCode file uploaded."

#### Example Usage

```bash
curl -X POST "http://localhost:3000/jot" \
     -F "file=@output.g" \
     -F "baseUrl=http://192.168.1.100"
```
